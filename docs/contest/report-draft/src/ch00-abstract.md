# 摘要

智能体正批量进入 openKylin 生态，能否长期、稳定、可控地记住用户信息，已经成为影响智能体可用性的关键能力；生态里已运行多家各有记忆机制的智能体框架，却缺少一套与之配套的系统级自动化评测工具。

现有做法有三点不足：人工检查难以规模化；一问一答覆盖不了冲突更新、相似干扰与行动复用；自动评分难以区分"记住了、误记了、不该记却记了"。

本作品"麟阁 MemHall"把每道题组织成"教→隔→考"三阶段剧本，按六能力×七题型组织成五套题包共 181 题，覆盖矩阵 36 格无空格；判卷只认对话流、记忆快照、行动轨迹、文件差异四类带哈希封印的运行证据，规则判卷打底、单 LLM 评委语义分类、判不了转人工复核，判卷器自身由金标准自检（错判 0）、诱饵负样本（188/188 拒收）、人工盲评（72 条双人分层抽样）三件质检背书；全链路收进一条命令，以 .deb 与 Windows 便携 exe 工具化交付。

正式横评在 openKylin 3.0 上覆盖 Hermes、KylinBot、OpenClaw、kylin-agent 四家完整框架智能体：3 题包 × 4 轮共 48 场，统一模型经网关强制对照，冻结试卷同卷同序；产出六维雷达、均值±置信区间与六态判定构成，每个数字都能下钻到证据哈希。〔待填：四家正式成绩，待全量矩阵出数后与第七章同步回填〕
