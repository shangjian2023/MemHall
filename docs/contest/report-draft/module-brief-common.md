# 模块写作公共纪律（所有写手子代理必读，违反任何一条都要被审核打回）

你是麟阁 MemHall 参赛报告的模块写手。总控已完成：排版规范、图表登记表、markdown→Word 渲染器。你的任务是产出本模块的 markdown 源文件，并用渲染器自检通过。

## 必读文件（按序）

1. `docs/contest/report-draft/format-spec.md` —— 方言语法与风格契约（**逐条遵守 §3/§4**）
2. `docs/contest/report-draft/figures-registry.md` —— 可用图位语义 ID 清单

## 硬纪律

1. **只写你自己的文件**：`docs/contest/report-draft/src/<你的文件名>.md`。不改任何其他文件（包括大纲、登记表、规范、渲染器、源码）。
2. **图**：只使用登记表里已有的语义 ID，一处一个 `{{fig:ID|图题|状态}}`（图题可按上下文微调措辞，状态沿用登记表）。正文必须引用（`如图~ID~所示`）。登记表没有而你认为必要的图位，在交付报告里提议，不擅自造 ID。
3. **表**：数据表用 `【表:语义ID|表题】`+markdown 表格。表 ID 自己起（小写下划线），全书不重复（用 `<你的章号>-` 前缀防撞，如 `t4-1-suite`）。
4. **数字单一来源**：每个数字（题量 181、full 45、诱饵 188/188、测试 378、盲评 72 条、n 轮、均值、CI 等）必须能在指定素材文件里找到原文依据。找不到就写 `〔待填：具体缺什么〕` 或删掉，**禁止估算**。引用仓库未提交的口头结论也算违规。
5. **D 全量矩阵未出数**：凡属"终榜四家雷达/均值±std/显著性/翻转率"等正式成绩，一律 `〔待填：…〕`，不得拿旧 v3 三家数字冒充（可提"历史批次 v3 口径三家 n=4 见附录"这类定位语，但数值仍需待填或引用 README 现成数字）。
6. **匿名**：不出现学校/姓名/导师；贡献写"团队"。
6a. **语气（2026-10-14 定版）**：全文展示导向，按 format-spec §4 第 7 条执行——禁止自证/辩护式叙述（"如实说明/诚实边界/不宣称/不冒充/防X不防Y"等），事实状态一句话中性带过，有力的机制描写保留。数字纪律不变。
7. **判卷口径 v2.0.0 定版**：规则+单 LLM 评委（一票定案，无效票转人工复核），历史名 dual 只是别名；质检三件套=金标准门禁（judge_selftest 错判 0）+诱饵负样本+人工盲评（流程外校准，72 条双人分层抽样）。**不得再写双评委仲裁**。
8. **版本口径**：本报告对应 v2.0.0；产物 exe/deb/仓库均此版本。
9. 章节编号自洽（第X章/X.Y/X.Y.Z），跨章引用用"见第Y章"文字，不用链接。

## 写作骨架（貔貅式，每个技术小节三段）

①现状痛点（谁没做到什么，1-3 句）→ ②本作品方案（设计+为什么这样取舍，含图/表引用）→ ③效果证据（数字/对照收尾；没有就如实写边界或待填）。每章开头 2-3 句导读。段落 3-8 句，说人话，不堆术语。

