## 作品重点

**背景：** 长期助理需要持续遵守约定、更新旧信息、区分相似项目，也需要知道哪些信息不应保留。

**架构：** 教、隔、考三阶段连接统一适配器、证据采集、规则与语义判卷，以及六维报告和逐题复查。

**场景：** 从目录和模板复用、记忆机制调优，到智能体版本回归，形成“运行—定位—修改—再验证”的工作流程。

**创新：** 在麒麟本机直接测，也能远程管理；检查重启、权限和网络变化后的记忆表现；从UKUI桌面启动并接收完成提醒；用.deb交付程序和题库；升级后用同一套题复查，并核对任务是否实际办对。
