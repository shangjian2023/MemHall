## 结论与参赛判断

MemHall 已具备参赛作品的主体：六维能力模型、三阶段任务编排、异构智能体适配、四类证据契约、分层判卷、CLI/UI、统计报告及 openKylin 打包路径。它最有说服力的贡献，是将长期记忆的失败变成可解释、可追踪的工程实验，而不是再做一个只给总分的问答排行榜。

当前应优先修补证据和发行闭环。18 轮真实归档有 14 轮通过当前完整性检查，4 轮存在缺失；本批实际只有单个语义评委。源码中的运行依赖、Windows 通道、配置写入、评分展示、统计与打包问题已在本地修复。作品介绍已据此写成可编辑 Word，明确区分已实现机制、已有实测和待完成验收。

本报告中的“通过 verify”指当前校验器覆盖的项目通过，不意味着具有外部签名的真实性认证。没有原始证据的部分不能靠补写内容使其通过。

## 尚存问题与建议

### R01 / P1：真实归档缺口必须在提交前处理

逐轮结果见 [verification.json](verification.json)。失败项为：

| run_id | 缺口 | 可采取的处理 |
|---|---|---|
| 20261010-073953-hermes | update-005/006/007 的 confound/probe 对话缺失，inject 无记忆快照，共 9 项错误 | 恢复真实原文件或重跑；将该轮作为证据不足留档，不能伪造阶段 |
| 20261010-163950-kylinbot | boundary-005 缺 probe dialogue | 恢复真实原文件或重跑 |
| 20261011-145803-kylinbot | 同上 | 同上 |
| 20261011-073455-hermes | 缺 radar.png | 找回原图；若重渲染，只能作为派生产物重新形成有来源的新归档 |

已尝试从原始 metrics 重建最后一项雷达图，但新图 SHA-256 与 manifest 期望值不同；派生图单独保存在本审计目录，未替换原始归档或修改封印。本次 Word 保持 14/18 通过的真实状态。

通过的历史归档也有警告：部分缺少题库级及逐题级封印，部分 inject 仅一张快照。哈希可检出变化，但没有外部签名或可信时间戳时无法单独证明不可伪造。下一版应统一记录 git commit、题库指纹、评分版本和逐题证据封印。

### R02 / P1：修复源码与正式发行尚未闭环

现存 .deb/exe 来自先前构建，不能当成修复版。在干净 openKylin 上重建、安装、跑 mock、跑至少两款真实智能体，再保留版本、依赖及试装记录。建议同时形成 wheels 的许可证清单、NOTICE/SBOM；本轮仅补齐打包依赖与元数据，没有宣称已经完成这项治理工作。

### R03 / P1：单评委可靠性与比较推断需要校准

本批所有 full/chains manifest 的 `judge.model_b` 为空。虽然模式名是 dual，实际是规则 + 单 LLM A；且被测模型和评委使用相同模型标识。应安排独立模型评委、人工抽检及单/双判对照，再主张判卷准确性。离线 judge selftest 的 0 错判不代表真实 LLM 评委 0 错判。

相同题目跨轮重复，当前合并方向票 p 值未校正相关性；轮数也只有 4。应按 case 聚类比较或以独立新题作验证。修正后的头部近似功效需求约 58 轮，仅是小样本方差下的估计，不能当成承诺的达标轮数。

### R04 / P2：构念与实际证据还不完全对齐

部分真实车道每条消息以独立进程发送，recall 更接近写后即取，persist 更接近跨干扰保持，尚不能充分区分真实会话内检索与跨会话持久记忆。建议增加具备持久会话的适配器，并公开每条车道的测量定义。

真实动作记录覆盖有限，文件变化没有内容指纹，记忆导出面也异构。路径存在或文件发生变化不足以证明任务内容正确。建议增加内容级验收、真实工具动作采集，并按证据能力分组呈现，避免把不同导出面的结果当作同条件比较。

### R05 / P2：加试隔离不等于抗定向重构

公开模板、槽位池与 seed 可重建 heldout。排除发行包中的 heldout 只解决直接分发问题。应采用私有槽位池、延迟公开 seed，并加入模板外改写题；难度标签须通过真实表现标定，而不能只凭生成参数或覆盖矩阵断言数据设计已校准。

### R06 / P2：系统与录屏证据还需扩大

本地 2026-09-29 Hermes systest 记录 4/4 通过，但仅能支持对应历史条件。断网项目验证的是本地记忆库存活，不能证明云端推理离线可用。本轮未取得三家同条件系统测试的新证据。

本次直接读取 GitHub 官方 v1.3.2 Release API（200），附件仅为 exe 与 deb，仓库原“5 分钟演示视频”链接未提供视频。已修正 README 入口。元数据见 [github-release-v1.3.2.json](github-release-v1.3.2.json)。这不能排除团队已另存视频，仍需补齐可访问链接并核验内容。

命题要求至少两款真实智能体在 openKylin 桌面完成流程录屏。mock 截图和离线样例只能证明工具链连通，不能替代这项材料。更新后的讲稿见 [demo-script.md](../../demo-script.md)。
