# OKIM-Bench 交付包（2026-09-24）

智能体长期记忆自动化评测系统 —— 当前进度快照，供队友 A/B/D/E 对接。

## 目录结构

```

  vm_exec.py                # D 对接参考：VirtualBox 虚拟机 SSH 执行助手（需 pip install paramiko）
  vm_demo_score.py          # 虚拟机内评分演示
  out/

    brain_final.db          # 首跑记忆库快照（证据）
  README.md                 # 评分器使用说明

research/

cd okim-bench

```

## 各角色对接点

- **A（系统/适配器）**：`adapters/kylinbot.py` 是适配器范例；统一接口 = ProbeSpec/EvidenceBundle/MemorySnapshot，任何智能体实现 `load_snapshot()` 即可接入。
- **B（题库）**：ProbeSpec 即题目契约，参照 `scoring/selftest_gold.py` 与 `realrun_score.py` 里的 PROBES 写法；注意 §8 实测结论——KylinBot 当前"存了取不出"，update/false_reuse 题区分度高。
- **D（引擎/环境）**：`vm_exec.py` 是现成的虚拟机执行通道（SSH paramiko，密码走 `VM_PASS` 环境变量）；brain.db 取证务必先 `PRAGMA wal_checkpoint(TRUNCATE)` 再拷贝。
- **E（交付）**：`out/realrun/radar.png` 与 `out/real_judge_run.json` 是现成的答辩实证素材。

## 注意事项

- 不含任何密码/密钥；虚拟机密码与 API key 请线下单独传递，运行时走环境变量。
- `_deps/`（paramiko 等第三方库）未打包，`vm_exec.py` 需自行 `pip install paramiko`。
- 双 judge 当前为 Kimi 家族双模型（仅验证链路），正式评测需换跨家族组合（如 DeepSeek + Qwen）。
