# README 配图来源

- `hero.svg`：为仓库首页制作的可编辑矢量横幅；不包含评测成绩。
- `workflow.png`：作品报告已有的“教—隔—考”流程图。
- `report.png`、`evidence.png`：归档 `20261015-054036-kylin-agent` 的真实报告与逐题判定截图。截图为同一次运行的界面示例，不代表跨框架排名。
- `ukui-notification.png`：真实 UKUI 图形会话中的历史归档回看与完成通知演示，通知本身标注了回看性质。

PNG 保留源文件原始像素；来源与校验值见 `provenance.json`。历史图片继续保留在上级 `images/` 目录。
